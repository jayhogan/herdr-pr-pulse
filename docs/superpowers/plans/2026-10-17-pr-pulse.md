# herdr-pr-pulse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A herdr plugin TUI that shows the status of Jay's GitHub PRs, grouped into stacks and
ranked by what needs attention, with agent state from herdr and "what changed since you looked"
marks.

**Architecture:** One binary, `herdr-pr-pulse [workspace|mine] [--fixtures]`. Pure modules
(`model`, `stacks`, `attention`, `changes`, `workspaces`) turn GitHub data and a herdr snapshot
into a `Screen` view model (`app`), which `ui` draws with ratatui. GitHub is read by shelling out
to `gh api graphql` on a background thread; results are shared between running copies through
a cache file in the state dir. herdr is polled every 2 s with `herdr api snapshot`.

**Tech Stack:** Rust 2024, ratatui 0.30, crossterm 0.29, serde/serde_json, chrono; insta +
tempfile for tests.

**Spec:** `docs/superpowers/specs/2026-10-17-pr-pulse-design.md` (read it first; section numbers
below refer to it). Mockups: https://claude.ai/artifact/AzYJKRJJtWuBPCad66Tv7z (boards 1–6).
Template repo: https://github.com/jayhogan/herdr-skill-timeline. Clone it to a scratch directory
and copy its conventions.

## Global Constraints

- Package and binary name `herdr-pr-pulse`; `edition = "2024"`; work happens on branch
  `pr-pulse-mvp`.
- Dependencies exactly: `chrono = { version = "0.4", default-features = false, features = ["std",
  "clock", "serde"] }`, `crossterm = "0.29"`, `ratatui = "0.30"`, `serde = { version = "1",
  features = ["derive"] }`, `serde_json = "1"`; dev: `tempfile = "3"`, `insta = "1"`. No async
  runtime and no other crates.
- State dir: `${XDG_STATE_HOME:-~/.local/state}/herdr-pr-pulse/` (same resolution as the
  template's `Store::default_location`).
- herdr binary: `$HERDR_BIN_PATH`, falling back to `herdr`. GitHub only through the `gh` CLI;
  never read, print or store tokens. No GitHub mutations.
- Timings: herdr snapshot every 2 s; GitHub every 60 s plus `r`; `UNKNOWN` merge-state recheck
  once, 10 s after the fetch that returned it.
- Colors: only `Color::Red`, `Green`, `Yellow`, `Cyan`, `DarkGray` (ANSI 8, "dim"), `White`
  (only as text on the red ▲▲ row), `Reset`/default, plus `Modifier::BOLD` and
  `Modifier::REVERSED` (header bar). Never `Blue`, `Magenta`, any `Light*`, or RGB/indexed
  colors. Every colored element also carries a glyph or a word.
- Errors are `Result<T, String>` with human-readable messages, as in the template. The one
  exception is `GhError` (Task 9), which the UI needs to tell apart.
- Every commit leaves `cargo test` passing and `cargo clippy --all-targets -- -D warnings` clean.
  Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Fixture clock: `NOW = 2026-10-17T14:32:26Z`; fixture fetch time `2026-10-17T14:32:08Z`
  (header reads "18s ago"). Tests format clock times in UTC.

## Review Focus

1. **PRs with no checks at all, or repos with no required checks.** These must show `– none` or
   fall back to all checks (spec §7), never "failing". Pinned in Task 2
   (`no_checks_is_none`, `no_required_checks_falls_back_to_all`).
2. **Head branch deleted, or a PR from a fork.** `baseRef.compare` is null and `headRef` is
   missing. Expect no behind count and no panic. Pinned in Task 2 (`null_compare_has_no_behind`).
3. **Tiny or short panes.** Width under 34 or height under the content must not panic, and the
   cursor row must stay visible. Pinned in Task 7 (`tiny_terminal_does_not_panic`,
   `cursor_scrolls_into_view`).
4. **Long or wide-character titles** (emoji, CJK). Columns must stay aligned: truncate by display
   width with `…`. Pinned in Task 7 (`wide_chars_keep_columns_aligned`).
5. **`gh` missing from PATH in a herdr pane, or a corrupt state file.** Expect the banner
   "gh not found" and no crash; a corrupt state file is moved to `.bak` and starts empty. Pinned
   in Task 9 (`classify_not_installed`) and Task 10 (`corrupt_file_is_backed_up`).
